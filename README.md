# Élan

Élan : application gratuite de suivi d'habitudes (PWA) : séries, jauges 0-100 %, statistiques, hors ligne.
Les données restent sur l'appareil (localStorage), aucun serveur n'est nécessaire.

Fichiers : `index.html`, `style.css`, `app.js` (toute l'appli), `manifest.json`, `sw.js` (hors ligne), `icons/`.
Hébergement : n'importe quel hébergeur de fichiers statiques (GitHub Pages, Cloudflare Pages…).
